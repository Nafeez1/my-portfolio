## Quick Deploy (5 Minutes)

### Step 1: Go to Vercel
Open this link: **https://vercel.com/signup**

### Step 2: Sign Up with GitHub
- Click "Continue with GitHub"
- Authorize Vercel to access your GitHub

### Step 3: Import Your Project
1. After login, click **"Add New..."** → **"Project"**
2. You'll see your GitHub repositories
3. Find **"my-portfolio"** in the list
4. Click **"Import"** next to it

### Step 4: Configure (Auto-detected)
Vercel will automatically detect:
- Framework: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

**Just click "Deploy"** - Don't change anything!

### Step 5: Wait 2 Minutes
Vercel will:
- Install dependencies
- Build your portfolio
- Deploy to their CDN
- Generate your live URL

### Step 6: Get Your Live URL
You'll get a URL like:
- `my-portfolio-nafeez1.vercel.app`
- Or custom: `your-name.vercel.app`

## Alternative: Netlify

### If Vercel doesn't work, use Netlify:

1. Go to: **https://app.netlify.com/signup**
2. Sign up with GitHub
3. Click **"Add new site"** → **"Import an existing project"**
4. Choose GitHub → Select **"my-portfolio"**
5. Settings (auto-detected):
   - Build command: `npm run build`
   - Publish directory: `dist`
6. Click **"Deploy site"**
7. Get URL: `your-portfolio.netlify.app`

## After Deployment

### Add EmailJS (Optional)
In Vercel/Netlify dashboard:
1. Go to Settings → Environment Variables
2. Add:
   - `VITE_EMAILJS_SERVICE_ID`
   - `VITE_EMAILJS_TEMPLATE_ID`
   - `VITE_EMAILJS_PUBLIC_KEY`
3. Redeploy

### Custom Domain (Optional)
1. Buy domain from Namecheap/GoDaddy
2. Add in Vercel/Netlify settings
3. Update DNS records
